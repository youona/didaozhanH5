# 地道战 · 交互式网页

> 1942 年的冀中平原上，人往土里走，路才活下来。

一个对标腾讯新闻《长征 90 周年》H5 的交互叙事网页。内容取材于冀中冉庄地道战的史实、1965 年同名影片的拍摄幕后，以及今日遗址的留存。全站八段，从"地上没路了"讲到"地上照常种庄稼"。

- 入口：`index.html`
- 运行环境：现代浏览器（Chrome / Edge / Safari / Firefox），无需服务器、无需构建、无需联网
- 依赖：无。零第三方库、零构建工具、零外链 CDN

## 怎么跑

直接双击 `index.html` 就能看。

也可以用本地服务器（和双击效果一致，只是规避个别浏览器对 `file://` 的限制）：

```powershell
python -m http.server 8123 -d work/didao-ds-new
# 然后打开 http://127.0.0.1:8123
```

地址后加 `#0`…`#7` 可直接跳到某一段（如 `index.html#4` 进"守"）。

| 段 | data-key | 标题 | 讲什么 | 交互 |

| 三 | `hide` | 洞口就在脚下 | 锅台、炕面、马槽、井口、衣柜等洞口伪装 | 八张 3D 翻卡 |
| 四 | `guard` | 五防：水毒火钻破 | 防水、防毒、防火、防钻、防破坏 | 五道场景判断题 |
| 五 | `fight` | 打一枪，换一个地方 | 诱敌深入、高房与街巷火力网 | 25 秒限时点击移动靶 |
| 六 | `person` | 张森林，三十四岁 | 拒交名单与地道图被活埋；狱中《就义辞》 | 点字补全"志未酬" |

## 技术栈

| 层 | 选择 | 为什么 |
|---|---|---|
| 框架 | 无，classic script + `window.DD` 命名空间 | 参考对象本身是原生实现；而且 `file://` 下 `type="module"` 会被 CORS 拦死，普通 script 才能双击就开 |
| 数据 | `js/data/content.js` 挂到 `DD.content` | 同理：`file://` 下 `fetch('x.json')` 会失败，文案只能是 JS |
| 舞台 | 固定 1672×941 + `transform: scale()` | 与参考一致，所有坐标写死，缩放在外层一次算完，内部不管响应式 |
| 竖屏 | `#rotor` 宽高互换 + `rotate(90deg)` | 手机竖着拿也能看横屏构图，参考页同款做法 |
| 动画 | Web Animations API（`DD.motion`） | 浏览器原生、可取消、时间线可控，不需要 GSAP |
| 图形 | SVG（拼图路径 / 折线）+ Canvas（海报） | 几何全部可控可调，不依赖图片素材 |
| 音频 | WebAudio 纯合成（`DD.audio`） | 钟、枪、土落都是振荡器和噪声包络，不用音频文件 |
| 状态 | localStorage（`didao-ds.v1`） | 只存进度和静音，不需要后端 |
| 适配 | 内层 `fit()` 缩放 + 竖屏判定 | 转屏、窗口变化重算一次即可 |
| 素材 | 木刻版画风图片 + 程序化纹理 | 视觉统一，且省掉"找不到合适历史照片"的版权风险 |

## 素材与版权

- **背景图**：木刻/石印风格插画，AI 生成后人工筛选，只作氛围示意，**不作史料图像**，页面标注"示意"
- **程序化图形**（SVG/Canvas）：本项目原创
- **史实口径**：分【史料】【影片】【幕后】【示意】四类标签，电影情节与史实分别标注，不混写
- 素材来源、文件尺寸与校验记录见 `assets/来源.md`；源目录只读，副本在本项目内

关键数据（据点 1753 座、封锁沟 4187 公里、干线 2.25 公里、全长 32 华里、1945-04-01 相持 13 小时等）均按冉庄地道战纪念馆公开口径，出处标注在每个 section 底部。

## 开发

改文案 / 改参数：编辑 `js/data/content.js`。
- 翻卡：`DD.content.cards`（8 项，翻 6 张算完成）
- 五防题：`DD.content.quiz`（选项正确项是 `options[i].ok`，不是单独的 `answer` 字段）
- 拼字：`DD.content.poem`（`blank: '志未酬'`，三个字）
- 刨土：`DD.content.dig`（`target: 3.0` 米，`stepPerPx: 0.012`）
- 打靶：`DD.content.shooter`（`seconds: 25`，`need: 8` 命中）

改动画：easing 与时长集中在 `js/motion.js`（`EASE` / `EASE_SOFT`），别在模块里写死。

加一段：`index.html` 里加 `<section class="scene" data-i="8" data-key="xxx">`，在 `js/stage.js` 里把 `TOTAL` 从 8 改 9，再写一个模块按 `DD.modules.push({ init })` 注册。

验收（在仓库根目录跑，脚本在仓库级 `tools/` 下，不在本项目内）：

```powershell
python tools\qa.py
```

31 项断言：八段逐个截图、六种交互真点一遍、hash 定位、localStorage、静音、重开复位、控制台报错数。产物在 `work/didao-ds-new/qa-out/`（`report.json` + `s0.png`…`s7.png`）。默认先探 9222 端口上的调试浏览器直接复用，没有才自己起 headless。

## 已知限制

- 开场没有视频（本机无 ffmpeg），用版画背景 + WebAudio 替代；参考页的视频降级路径也是静态图
- 手机竖屏时整页旋转 90°，页面底部提示"把手机横过来，看得更敞亮"（不是顶部）
- 未接入微信分享 SDK；尾段海报是 Canvas 重绘，可用「保存图片」下载成 PNG
- 找洞口的八个热点是纯盲找，手机没有 hover 提示，只能靠试错（45 秒）
- 战果的「用时」依赖 `stage.js` 的 `state.stats.startedAt`，清过缓存的旧存档第一次会走「（本局）」兜底
- 背景图自带一点版画纸边，靠 `background-size` 放大裁切，极宽屏下可能露出极细一线
- 素材为 AI 生成的风格化插画，**不是史料影像**，页面已标注；正式发布前如需史实照片，要换成公共领域来源并注明出处
